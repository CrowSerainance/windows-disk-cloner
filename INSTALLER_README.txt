Windows Disk Cloner - Installation Instructions
================================================

IMPORTANT: This application requires Administrator privileges to function properly.

SYSTEM REQUIREMENTS:
- Windows 10 or later (64-bit)
- Administrator privileges
- At least 100 MB free disk space

INSTALLATION:
1. Run this installer as Administrator (right-click -> Run as Administrator)
2. Follow the installation wizard
3. The application will be installed to Program Files\WindowsDiskCloner

USAGE:
- Launch "Windows Disk Cloner (GUI)" from the Start Menu
- Or run DiskClonerGUI.exe from the installation directory
- ALWAYS run as Administrator for full functionality

FEATURES:
- Clone entire disks (disk-to-disk)
- Create disk image backups (drive-to-image)
- Resize partitions to fill available disk space
- Visual progress tracking
- Detailed activity logs

WARNINGS:
- This tool can permanently erase data on target disks
- Always verify source and target selections before proceeding
- For system drive cloning, consider using Clonezilla Live bootable USB
- Always maintain backups of important data
